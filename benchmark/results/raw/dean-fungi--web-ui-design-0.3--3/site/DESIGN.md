# Dean Fungus Group species guide: design notes

Mode: Read (lookup). Family: Editorial. Stack: one plain index.html, no build.

- Colours: moss #4a5d23 and cream #f3ecd8 are the group's own. Red #b3261e is used only for Deadly. Poisonous uses bracken brown #7a4b0c. Each label also has its own icon and text, so colour is never the only signal.
- Type: system serif (Palatino/Georgia stack) for the page, system sans for filters and labels. No web fonts.
- Signature: the lookalike panel beside each species, built from the PAIRS list.
- Content rules from the recorder: one banned word (the recorder knows which); labels are exactly "Eaten by members", "Not worth eating", "Poisonous", "Deadly"; Poisonous and Deadly entries carry the 999 / NHS 111 line; no lookalike pairs beyond those the group stated.
- Draft marks (labelOk / detailsOk per species, SAFETY_WORDING_APPROVED) show until the recorder confirms.
