# Harbour Swim Club design

## Brief
| Item | Value | Source |
| --- | --- | --- |
| Subject | Volunteer-run swim club, Falmouth | user |
| Primary action | Join (first visit free) | assumed (left to us) |
| Audience and device | Parents and older members, on phones, often poolside. They mostly check timetable and prices | user |
| Assets | Navy #1b2a4a, yellow #f2c230, logo.svg | user |
| Must keep and scope | Refresh. Keep every session, price, the join form and news. No build step | user |

## Direction
Friendly and legible, not flashy. Large type (18px body), 48px touch targets, navy and yellow as in the logo. Yellow is only used on navy or as a small accent bar, because yellow text on white fails contrast. Fonts are the system stack, so there is nothing to load or host.

## Components
- Primary button: navy with yellow text on light sections, yellow with navy text on navy.
- Timetable: a real `<table>` on wide screens. Under 820px each row becomes a card, using `td:nth-child` labels in CSS. Adding a row means copying a `<tr>` with six `<td>`, in the same column order.
- Day filter buttons are generated by script.js from the Day column, so no markup to maintain.
- Notices: a `<details>` list that replaces the scrolling ticker.

## Decisions
| Decision | Rationale | Date |
| --- | --- | --- |
| Removed the scrolling ticker | Moving text is unreadable for many people and was clipped. Notices are now a static list | 2026-10-20 |
| Sticky "Join the club" bar on phones | Keeps the primary action one thumb away. Hides while the form is visible | 2026-10-20 |
| Form validates inline | Replaces alert() popups. The form still has no backend (see README note in reply) | 2026-10-20 |
