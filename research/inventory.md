# Web UI design skills inventory (snapshot 2026-10-19)

## Method and sources for every number
- Stars and last push: `gh api repos/OWNER/REPO` (backed by `https://api.github.com/repos/OWNER/REPO`). Every repo row cites its GitHub URL, and the star and date figures come from that API call on 2026-10-19.
- Installs: skills.sh search API, `https://skills.sh/api/search?q=<term>` (exact counts), cross-checked against the leaderboard at https://skills.sh (rounded). Installs are per skill, so multi-skill repos show the top skill and, where noted, the sum of design-relevant skills.
- Format and concreteness: shallow clones read under `clones/` (skills.sh and GitHub are the cited sources for the numbers; clone reading is my own assessment).
- Caveat on traction: star and install totals look very large and some look inflated. `designed-by-ai/skills` shows 897K installs on 19 stars (https://github.com/designed-by-ai/skills). `uizze.sh/ui-taste` shows 637K installs with no matching GitHub repo found. Treat install counts as a weak signal.
- Not swept: skillsmp.com and cursor.directory returned nothing through search. Smithery copies are tiny (e.g. smithery.ai/frontend-design 4.3K installs per https://www.skills.sh/site/smithery.ai). The two listed Claude marketplaces are covered via the GitHub repos.

## Top 8 to deep-read

1. **pbakaus/impeccable.** Highest-quality design process: modes (Persuade/Operate/Read/Experience), a craft-floor with absolute bans, critique/audit playbooks, and a real detector CLI with live browser mode. Closest to a complete design-director system. Read `skill/SKILL.src.md`, `skill/reference/craft-floor.md`, `critique.md`, `polish.md`.
2. **Leonxlnx/taste-skill.** Largest install base of any design pack (5.4M summed). Different approach: researched art-direction library, a house no-slop style, a browser inspector and a screenshot fix loop. Read `skills/taste-skill/SKILL.md` and the `research` and `evals` directories to see whether the claims are tested.
3. **nextlevelbuilder/ui-ux-pro-max-skill.** The only data-backed one: CSV tables of styles, palettes, type pairings, UX rules, landing patterns with a search CLI. Worth reading for what to steal as lookup data versus prose, and to judge data quality.
4. **anthropics/skills + claude-plugins-official `frontend-design`.** The baseline everything else is measured against (1.0M installs). Only ~70 lines, so cheap to read, and the newer version has concrete anti-tells (single-word accent, all-caps labels, 01/02/03 markers).
5. **emilkowalski/skills (`emil-design-eng`, `review-animations`, `animation-vocabulary`).** Best concrete motion and polish values (durations, easings, transform rules) with strong traction (1.9M summed). Gold for the animation-polish slice.
6. **jakubkrehel/skills (`better-ui`, `better-typography`, `better-colors`, `better-layout`, `make-interfaces-feel-better`).** Explicitly exact values (radius concentricity, shadows, cubic-bezier) split into small focused skills. Good model for decomposing a design skill into composable pieces.
7. **nutlope/hallmark.** Compact (558 lines) opinionated anti-slop design skill with ~30 reference files (slop-test, anti-patterns, typography, color, layout-and-space, motion) and URL/screenshot extraction. Short enough to read fully and compare against impeccable.
8. **vercel-labs/web-interface-guidelines via `web-design-guidelines`.** Terse, checkable rule list (about 100 bullets) that outputs `file:line` findings. The best example of a reviewable ruleset rather than creative guidance. Pair with `raphaelsalaja/userinterface-wiki` (104 per-rule files) if a second rule-pack comparison is wanted.

Runner-ups: ibelick/ui-skills (small deslop baseline), Dammyjay93/interface-design (product-UI specific), google-labs-code/stitch-skills `design-md` (the DESIGN.md contract), petergyang/no-ai-slop (cheap ban list), mengto/skills (scroll and glow effect recipes).

- Star counts above 100K for taste-skill, impeccable, and ui-ux-pro-max are what the API returned; I did not independently audit them for inflation.
- Could not verify skillsmp.com or cursor.directory rankings; web search did not surface them.
